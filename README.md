
# Todo Tracker

A simple Todo Tracker built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by All, Pending, and Completed
- Display total, completed, and pending task counts
- Validate empty task input
- Show an empty state
- Save tasks using browser localStorage
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Delegation
- localStorage

## Project Structure

    Todo-Tracker/
    ├── index.html
    ├── style.css
    ├── script.js
    └── README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Start adding and managing tasks.

## Data Storage

The application uses browser localStorage to save tasks. Saved tasks remain available after refreshing the page in the same browser.
